01

Roblox Games

ข้อมูลเกม ผู้เล่น การเข้าชม ฟีเจอร์ และผลตอบรับจากชุมชน

ดาวน์โหลดตัวอย่าง 20 แถว
Data Dictionary
Title
ชื่อของเกม
Creator
ผู้พัฒนาหรือสตูดิโอผู้อยู่เบื้องหลังการสร้างเกม
AgeRecommendation
ระดับอายุที่เหมาะสมของเกม ซึ่งแนะนำโดย Roblox
Active Players
จำนวนผู้เล่นที่กำลังเล่นอยู่ในปัจจุบัน
Favorites
จำนวนผู้ใช้ที่บันทึกเกมนี้ไว้เป็นเกมโปรด
Visits
จำนวนครั้งที่เข้าเล่นทั้งหมดนับตั้งแต่เปิดตัว (หน่วยเป็นล้านหรือพันล้าน)
Voice Chat
การรองรับระบบแชตด้วยเสียง
Camera
การรองรับการตั้งค่ามุมมองกล้อง
Created & Updated
วันที่สร้างเกมและวันที่อัปเดตล่าสุด
Server Size
จำนวนผู้เล่นสูงสุดที่รองรับต่อเซิร์ฟเวอร์
Genre
ประเภทของเกม (หากมีข้อมูล)
Likes & Dislikes
ตัววัดผลตอบรับจากชุมชนผู้เล่น (จำนวนกดถูกใจและไม่ถูกใจ)
Game Link
ลิงก์ตรงสำหรับเข้าสู่หน้าเกม
DateFetched
วันและเวลาที่จัดเก็บข้อมูลนี้
02

Learning Platform

ข้อมูลหลักสูตร การลงทะเบียน การเข้าเรียน ผลการเรียน และระยะเวลาการใช้งาน

ดาวน์โหลดตัวอย่าง 20 แถว
Data Dictionary
ลำดับ
ลำดับที่ของรายการข้อมูลในระบบ
รหัสหลักสูตร
รหัสประจำวิชาหรือรหัสอ้างอิงของหลักสูตร
ชื่อหลักสูตร
ชื่อของรายวิชาหรือหลักสูตรการเรียนรู้
ภาษา
ภาษาที่ใช้ในการจัดการเรียนการสอน
รูปแบบการเรียน
รูปแบบและเงื่อนไขเวลาในการเรียน (เช่น เรียนตามกำหนดเวลา)
ประเภทหลักสูตร
หมวดหมู่หรือรูปแบบสื่อการเรียนรู้ (เช่น MOOC)
สถานะหลักสูตร
สถานะการเปิดใช้งานของรายวิชา (เช่น เปิด หรือ ปิด)
วันเปิดเรียน
วันที่เริ่มเปิดให้เข้าเรียนในรายวิชา
วันปิดเรียน
วันสิ้นสุดการเปิดเรียนของรายวิชา
จำนวน(ผู้ลงทะเบียน)
จำนวนผู้เรียนทั้งหมดที่กดลงทะเบียนในวิชานี้
จำนวนผู้เข้าเรียน
จำนวนผู้เรียนที่เข้าใช้งานหรือเริ่มเรียนจริง
จำนวนครั้งที่เข้ารายวิชา(ครั้ง)
จำนวนครั้งทั้งหมดที่มีการเข้าใช้งานในรายวิชานี้
ผู้สอบผ่าน
จำนวนผู้เรียนที่เรียนผ่านเกณฑ์และสอบผ่านวิชา
เวลาเรียนทั้งหมด
รวมระยะเวลาที่ผู้เรียนทุกคนใช้เรียนในรายวิชานี้ (ชั่วโมง:นาที:วินาที)
03

YouTube Channel

ข้อมูลช่อง หมวดหมู่ ประเทศ ผู้ติดตาม ยอดชม และจำนวนวิดีโอ

ดาวน์โหลดตัวอย่าง 20 แถว
Data Dictionary
channel_name
ชื่อของช่อง YouTube
view_count
จำนวนยอดเข้าชมวิดีโอรวมทั้งหมดของช่อง (Total Views)
category
หมวดหมู่หรือประเภทเนื้อหาของช่อง (เช่น Music, Gaming, Entertainment)
country
รหัสประเทศที่ลงทะเบียนของช่อง (เช่น KR, US, TH)
defaultLanguage
ภาษาหลักที่ตั้งค่าไว้สำหรับช่อง
subscriber_count
จำนวนผู้ติดตามของช่อง (Subscribers)
created_date
วันและเวลาที่เริ่มสร้างช่อง YouTube
description
คำอธิบายเกี่ยวกับช่องหรือประวัติสังเขป
custom_url
ชื่อ URL เฉพาะหรือแฮนเดิลของช่อง (เช่น @blackpink)
video_count
จำนวนวิดีโอทั้งหมดที่อัปโหลดในช่อง
